Exercício 1 — Interruptor de Luz  

Desenvolva um componente que simule o funcionamento de um interruptor de luz. 

Requisitos: 

A luz deve iniciar desligada. 
Crie um botão para ligar e desligar a luz. 
Exiba na tela a mensagem "Luz ligada" ou "Luz desligada", conforme o estado atual. 
Altere o texto do botão de acordo com o estado da luz. 
 

Exercício 2 — Alterar Emoji 😊 

Desenvolva um componente que permita alternar entre dois emojis por meio de um botão. 

Requisitos: 

O emoji inicial deve ser 😐. 
Ao pressionar o botão, o emoji deve mudar para 😁. 
Ao pressionar o botão novamente, o emoji deve voltar para 😐. 
O botão deve permitir alternar entre os dois emojis continuamente. 
 
Exercício 3  Nome do Usuário  

Desenvolva um componente que permita ao usuário digitar seu nome e visualizar o texto digitado na tela. 

Requisitos: 

Crie um campo de entrada de texto utilizando o componente TextInput. 
Armazene o nome digitado pelo usuário em um estado. 
Exiba o nome em um componente Text abaixo do campo de entrada. 
Quando o campo estiver vazio, exiba a mensagem "Digite seu nome". 
 

Exercício 4 Mostrar e Ocultar Senha  

Desenvolva um componente com um campo de entrada de senha que permita ao usuário visualizar ou ocultar o conteúdo digitado. 

Requisitos: 

Crie um campo de senha utilizando o componente TextInput. 
Inicialmente, a senha deve permanecer oculta. 
Crie um botão com o texto "Mostrar senha". 
Ao pressionar o botão, a senha deve ficar visível. 
Ao pressionar o botão novamente, a senha deve voltar a ficar oculta. 
O texto do botão deve alternar entre "Mostrar senha" e "Ocultar senha". 
Exercício 5 — Sistema de Curtidas  

Desenvolva um componente que simule um sistema de curtidas, permitindo ao usuário adicionar e remover curtidas por meio de botões. 

Requisitos: 

O total de curtidas deve iniciar em zero. 
Crie um botão para adicionar uma curtida. 
Crie um botão para remover uma curtida. 
Exiba na tela o total atual de curtidas. 
Não permita que o número de curtidas fique negativo.
